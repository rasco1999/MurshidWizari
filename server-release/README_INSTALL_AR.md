# تحديث تطبيقَي الطالب والخادم — ١٥ أكتوبر ٢٠٢٦

تضم الحزمة إصلاحات التصحيح والمزامنة، وموعد انتهاء الاشتراك الدقيق للأوفلاين، وخطط الاشتراك بمعرّفَي `id` و`key`، وربط إشعارات المدارس عبر Android وiPhone. أسعار الخطط: ٨٠٠٠ د.ع لشهر، و١٥٠٠٠ د.ع لثلاثة أشهر. يبقى الحد المجاني ١٥ إجابة مقبولة، ويُحتسب عند إرسال الإجابة.

## تركيب الملفات

١. احتفظ بنسخة احتياطية من ملفات الموقع وقاعدة البيانات. طابق الملفات التي تغيّرت على الاستضافة منذ أرشيف `public_html 14.zip` قبل الاستبدال.

٢. ارفع محتويات مجلد `public_html` في هذه الحزمة إلى جذر الموقع نفسه. لا تُنشئ مجلد `public_html/public_html`. لا تتضمن الحزمة كلمات مرور أو مفاتيح خدمة أو قاعدة بيانات طلاب، ولا تستبدل إعدادات `config/config.php` أو `config/private.php`.

٣. إذا لم تُثبّت جداول إشعارات الآيفون سابقاً، نفّذ `migration/060_school_ad_apns.sql` مرة واحدة. يستخدم الملف `CREATE TABLE IF NOT EXISTS` ولا يحذف بيانات. احتفظ بجداولك الحالية إذا سبق تثبيتها.

٤. لتجهيز جداول أندرويد وجدول منع تكرار إعلانات المدارس، شغّل من مجلد الموقع:

```bash
php system/android-fcm.php --install
```

استدعاء الإرسال مدمج بالفعل في `includes/functions.php` المرفق؛ لا تحتاج تشغيل `--install-hook` لهذا الإصدار.

## إعداد الإشعارات

Android: ضع ملفَي مشروعك الحقيقيين `google-services.json` و`firebase-service-account.json` في مجلد `murshid-private` خارج `public_html`، أو اضبط المسار عبر `MURSHID_FCM_PRIVATE_DIR`. اسم حزمة أندرويد هو `com.murshidwizari.student`.

iPhone: أنشئ `config/native_push.php` باستخدام المثال المرفق ومتغيرات البيئة. يحتاج حساب Apple إلى مفتاح APNs صالح بصيغة `.p8` ومعرّفَي Team وKey. المعرّف المعتمد للتطبيق هو `com.muriq.murshid`. يجب أن يسمح بروفايل التوقيع بهذا المعرّف وبميزة Push Notifications.

أضف مهمتَي Cron كل دقيقة، مع استبدال `/FULL/PATH` بالمسار الحقيقي:

```bash
php /FULL/PATH/public_html/system/android-fcm.php --dispatch
php /FULL/PATH/public_html/system/school-ad-apns-cron.php
```

يمكن فحص إعداد Android دون إرسال رسالة:

```bash
php /FULL/PATH/public_html/system/android-fcm.php --check
```

جهّزت ملفات الربط والطوابير؛ وصول التنبيه الحقيقي يحتاج المفاتيح وCron وإذن الطالب واختبار هاتف فعلي. لا تثبّت مفاتيح الخدمة في GitHub أو داخل التطبيق.

## سلوك الأوفلاين

يفتح المدرب المحفوظ بعد التحقق السابق من الحساب. تنزيل موضوع للاختبار يتطلب اتصالاً واشتراكاً فعالاً بتاريخ انتهاء واضح. تُشفّر الأسئلة والإجابات وتُربط بالحساب، وتبقى صلاحية النسخة محدودة بانتهاء الاشتراك أو بسبعة أيام من آخر تحقق، أيهما أقرب.

يمكن حفظ إجابات الأنواع المدعومة البسيطة: الاختيارات، صح/خطأ، النص، الفراغات والمعاني. تظهر نتيجة تدريبية عند إمكان المقارنة بثقة؛ الصيغ التي تحتاج المحرك الكامل تنتظر التصحيح الرسمي من الخادم. محررات الوراثة والمطابقة والمسائل متعددة المراحل تبقى بحاجة إلى اتصال.

عند المزامنة يتحقق التطبيق من السؤال الحالي ومن الإجابات المسجلة سابقاً. تُحفظ المسودة إذا تغيّر السؤال، وتُعاد قراءة الإقرار بعد فقد الاستجابة. لا تمنح النتيجة التدريبية نقاطاً أو ترتيباً رسمياً. تجنّب تسجيل الخروج قبل مزامنة المسودات؛ الخروج الصريح يمسح المحتوى الخاص بالجهاز.

## تحقق بعد التركيب

استخدم حساب اختبار مستقل: افتح موضوعاً دون إرسال إجابة وتأكد من ثبات الرصيد؛ أرسل إجابة ثم أعد فتح السؤال وتأكد من عدم احتسابه مرتين؛ جرّب خطة الاشتراك والعودة من الدفع الخارجي دون منح اشتراك قبل تأكيد الخادم؛ نزّل موضوعاً، افصل الاتصال، أجب، أعد تشغيل التطبيق ثم أعد الاتصال.

المراجعة العلمية للمحتوى مستقلة عن اختبارات البرمجة. تقرير SQL المرفق يصف التصدير المرسل فقط، ولا يثبت حالة قاعدة الإنتاج بعد حذف التكرارات أو تعديلات الإدارة. لا تُعد استيراد قاعدة SQL القديمة ولا تكرر حذف التكرارات.
