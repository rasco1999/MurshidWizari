# المرشد الوزاري — Android Native

تطبيق أندرويد أصلي Kotlin + Jetpack Compose، لا يستخدم WebView ولا ينشئ قاعدة بيانات منفصلة.
الموقع: https://www.mur-iq.com. يبقى الحساب والأسئلة والتقدم والمفضلة والاشتراك والصورة مرتبطة بخادم الموقع.

## البناء
تُبنى نسخة Android Debug APK الموقعة بمفتاح التطوير داخل GitHub Actions.
للنشر على Play Store استخدم مفتاح Release خاصًا بك؛ لا تستخدم مفتاح Debug للإنتاج.
التثبيت يتطلب Android 7.0 أو أحدث (API 24).

## الأمان
HTTPS فقط، cookies للجلسة محفوظة داخل WebKit CookieManager (لتخزين جلسات HTTP دون WebView)،
لا تحفظ كلمة المرور، طلبات الكتابة تستخدم CSRF من mobile/bootstrap.php، والإجابات يصححها الخادم.
تغيير الصورة مباشرة من mobile/avatar.php بعد تفعيل تحديث الموقع v5.2.

## واجهات النسخة
تسجيل الدخول وإنشاء حساب/التحقق، الرئيسية، المواد، المواضيع، الاختبار وأنواع الأسئلة،
المرشحات، المفضلة والإبلاغ، ملاحظات السؤال، مراجعة الأخطاء، اختبار مخصص، تحدي اليوم،
البحث، طلبات إضافة سؤال وطلب المزيد، سجل المحاولات، الإشعارات، خدمة العملاء،
صورة الحساب، الاشتراك، ومظهر فاتح/داكن.
