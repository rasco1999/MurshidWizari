# تحديث «الإدارة» Native v2.0.0

**هذه الحزمة لتطبيق الإدارة الأصلي SwiftUI** ولا تحتوي على واجهة WebView. تطبيق الطالب لا يحتاج إعادة بناء بسبب هذه الحزمة.

## تركيب آمن
1. خذ نسخة احتياطية لقاعدة البيانات وملفات موقع mur-iq.com.
2. إذا لم تنشئ سابقاً جدول subscription_access_codes نفّذ الملف sql/subscription_access_codes.sql عبر phpMyAdmin مرة واحدة. CREATE TABLE IF NOT EXISTS لا يحذف جدول activation_codes.
3. ارفع admin/native-api.php إلى public_html/admin/native-api.php.
4. ارفع mobile/redeem-subscription-code.php إلى public_html/mobile/redeem-subscription-code.php، replacing the older edition to restrict only 1 / 3 months.
5. **لا ترفع محتويات ZIP كاملة فوق مجلد public_html.** فقط الملفات المحددة بالمسارات السابقة. ملفات تهيئة قاعدة البيانات والرموز الخاصة غير مشمولة.
6. افتح التطبيق الموقّع باسم «الإدارة» وسجل الدخول **ببيانات مدير المنصة نفسه**. إن كان التحقق الثنائي مفعلًا، أدخل رمزه. لا توجد كلمة مرور مضمّنة.
7. اختبر مستخدمًا تجريبيًا ثم كود مدة شهر واحد وثلاثة أشهر، وحالة إعادة استخدام كود، وقائمة الطلاب، وسؤالاً تجريبياً مخفياً، وإعلان مدرسة تجريبياً.
8. احرص أن أي مستخدم غير مسجّل أو طالب لا يستطيع تنفيذ عمليات الإدارة، وأن CSRF مطلوب لكل طلب تعديل أو حذف.

## ما يعمل بعد التثبيت
- إحصاءات حقيقية من DB
- أكواد مدة شهر واحد أو 3 أشهر فقط، إصدار/إلغاء/تعديل محدود/حذف ملغى
- الإعلانات بسعر 5000 دينار يومياً، إنشاء/تعديل/إيقاف/حذف
- البحث عن الطلاب وحظر/تفعيل حالة الطالب
- الاشتراكات 1/3 أشهر أو إلغاء
- تعديل الأسئلة ونشرها/إخفاؤها/حذفها، وإنشاء أسئلة MCQ جديدة مخفية حتى المراجعة
- عرض وإضافة وتعديل مواد وفصول الصفوف
- تسجيل دخول إداري بحماية دور admin وTOTP إن كان مفعلاً، وصلاحيات admin_can من الموقع، ومعاملات وقفل للكود من خدمة الطالب

## حدود مهمة
الخادم لم يُحدّث تلقائياً؛ **مجرد تنزيل IPA لن يُفعّل API**. ولم يتم اختبار التشغيل على قاعدة بيانات الموقع الحقيقية هنا. يجب تجربة كل قسم على حساب وبيانات اختبارية أولاً، والرجوع للنسخة الاحتياطية إن ظهرت اختلافات بين نسخ Schema.
واجهة إضافة السؤال تدعم MCQ المكون من أربعة اختيارات. بقية الأنواع تبقى متاحة من لوحة الموقع الموجودة.
مدة الكود لا تتغير بعد إنشائه، حفاظًا على سجل الاستخدام.
لا ترفع شهادة التوقيع أو كلمة مرور المدير إلى GitHub.
