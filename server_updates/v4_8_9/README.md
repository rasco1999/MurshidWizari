# المرشد الوزاري — ملحق الخادم v4.8.9

يضيف الملف `mobile/insights.php` مقارنة دقيقة بين دقة إجابات الأسبوع الحالي والسابق، مع الحفاظ على جميع حقول الـ API القديمة.

- احفظ نسخة احتياطية من `public_html/mobile/insights.php` قبل الاستبدال.
- ارفع `mobile/insights.php` إلى `public_html/mobile/insights.php` على الاستضافة.
- يتطلب وجود `mobile/common.php` و`includes/learning_catalog.php` الحاليين؛ لا تنقل أو تغير مفاتيح قاعدة البيانات.
- لا تظهر مقارنة دقة الأسبوعين إذا لم توجد إجابات في الأسبوعين، لئلا يظهر استنتاج مضلل.

هذا ملحق منفصل؛ التطبيق يعمل دون رفعه، لكن مقارنة الأسبوعين لن تظهر حتى يُرفع.
