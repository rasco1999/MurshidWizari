# Gallows City iOS preview
Standalone native SceneKit **technical demo**, NOT the complete Unity project.
Features: 3D procedurally generated city, shooting, cars, police heat, simple heist, Arabic and English HUD, local mission saves.
Build on macOS with Xcode: `bash GallowsCity_iOSPreview/build-ios.sh`.
Result: `GallowsCity_iOSPreview/dist/GallowsCity_iOS_PREVIEW_UNSIGNED.ipa`.
Unsigned IPA needs a compatible Apple certificate/provisioning profile for installation.
This work lives only on the `gallows-city-ios-preview` Git branch and does not modify the production site's main branch.
