# تطبيق «الإدارة» — المرشد الوزاري

تطبيق iPhone/iPad **منفصل** عن تطبيق الطالب، بحزمة `com.muriq.murshid.admin` واسم «الإدارة» وأيقونة ذهبية/كحلية مميزة.

## ما الذي يعمل فيه؟

- فتح لوحة إدارة الموقع الفعلية عبر HTTPS داخل متصفح آمن مدمج، مع جلسة الموقع الأصلية وصلاحيات المدير الموجودة فيه.
- شريط تنقل مستقل: الرئيسية، أكواد الاشتراك، إعلانات المدارس، المزيد.
- روابط مباشرة لأقسام الطلاب، الأسئلة، المنهج، الاشتراكات، الطلبات، التقارير، الدعم، وأمان الموقع.
- قفل محلي بـ Face ID/Touch ID أو رمز الجهاز؛ هذا **لا يلغي** طلب تسجيل الدخول الإداري والتحقق الثنائي على الخادم.
- إنشاء/إلغاء/تعديل بيانات/حذف الأكواد قبل الاستخدام، مع مدد **شهر واحد أو 3 أشهر فقط**.
- إضافة/تعديل/إيقاف/تفعيل/حذف إعلانات المدرسة؛ السعر 5 آلاف دينار لكل يوم.
- لا تُخزّن بيانات اعتماد المدير في التطبيق، ولا يحتوي على حساب مدير ثابت أو كلمة مرور مضمنة.

**مهم:** وظائف الأكواد والإعلانات الجديدة تعتمد على رفع `admin/mobile-console.php` وخدمة التفعيل وقاعدة البيانات من `server_updates/admin_app_v1` على الاستضافة، وهي غير مفعلة بمجرد بناء IPA. بقية الأقسام تنعكس من صفحات إدارة الموقع الأصلية وتتطلب أن تكون تلك الصفحات شغالة.

## البناء

شغّل GitHub Actions `Build Murshid Admin iOS IPA` ثم استخرج `Murshid_Admin_v1_0_0_BUILD1_unsigned.ipa`.

## التوقيع

النسخة المبنية هنا غير موقّعة. لتثبيتها **إلى جانب تطبيق الطالب** يجب أن يجيز ملف provisioning المعرّف المنفصل `com.muriq.murshid.admin` أو wildcard مطابق. شهادة `.p12` وحدها لا تكفي. لا ترفع الشهادة أو كلمة مرورها إلى GitHub، ولا تضعها في الشفرة أو Logs.
