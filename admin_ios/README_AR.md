# الإدارة v2.1.0 (Build 3) — تطبيق Native SwiftUI

**تم إلغاء WebView بالكامل.** تعتمد الواجهات والشاشات والأزرار على SwiftUI وليس صفحات HTML. تطبيق مستقل عن تطبيق الطالب وبنفس معرّف تطبيق الإدارة القديم com.muriq.murshid.admin.

## الواجهات
- الرئيسية: ست بطاقات بيانات حقيقية وإجراءات سريعة.
- الأكواد: شهر/3 أشهر فقط، إصدار 1–50 كودًا، نسخ/مشاركة مباشرة لمرة واحدة، إلغاء وتعديل المجموعة/الصلاحية وحذف الملغى.
- إعلانات المدارس: إنشاء، تعديل، تشغيل، إيقاف، حذف؛ 5000 دينار/اليوم.
- الطلاب: بحث بالحساب أو الهاتف وحظر/إعادة تفعيل الطلاب.
- الاشتراكات: شهر أو ثلاثة أشهر أو إلغاء من الخادم.
- بنك الأسئلة: بحث وتعديل نص السؤال/الإجابة/الشرح، إضافة اختيار من متعدد (أربع إجابات) كمسودة مخفية، نشر/إخفاء وحذف مع سجل تدقيق.
- المنهج: عرض الصفوف والمواد والفصول، إضافة وتعديل وإخفاء.
- تحدي المليون: تغيير تاريخ ووقت البداية والنهاية بتوقيت بغداد من التطبيق، مع تأكيد الحفظ، وعرض أفضل 50 مشاركاً وصورهم ونقاطهم.
- سلامة المنهج والأسئلة: فحص عدد الأسئلة اليتيمة، والأسئلة المنشورة ضمن فصل أو مادة مخفية، والأسئلة الاختيارية بلا إجابات، والفصول اليتيمة، وبقايا الفرنسية. الفحص للقراءة فقط ولا يحذف أو يصلح بيانات دون مراجعة.

## ملاحظة نشر مهمة
يعمل التطبيق من خلال HTTPS/JSON على مسار public_html/admin/native-api.php.
**قبل رفع ملف API على الاستضافة، تظهر رسالة خطأ حقيقية؛ لا توجد بيانات وهمية أو واجهة ويب بديلة.**
هذا المسار يعتمد على ملفات config/config.php, includes/auth.php, includes/totp.php, includes/platform_tools.php, includes/prize_contest.php وبيانات site MySQL الأصلية. ثبت أيضًا ملف SQL وخدمة تفعيل الطالب من server_updates/admin_app_v1 وفق README السابق.
**لإصدار 2.1:** استبدل `public_html/admin/native-api.php` بالملف المحدّث المرافق، بعد أخذ نسخة احتياطية. لا يُرسَل موعد التحدي إلى النسخة القديمة من API.
جميع العمليات الحساسة تتطلب admin role, session, CSRF, صلاحيات admin_can, rate limits؛ التحقق الثنائي في التطبيق أصلي.
لا تضع بيانات المدير ولا شهادة التوقيع ضمن GitHub أو التطبيق.
الواجهة بُنيت مع افتراض مخطط قاعدة بيانات الموقع الذي تمت مراجعته؛ اختبر كل عملية بحساب تجريبي بعد رفع API. لم ننشر على الموقع الحي، ولم نختبر تغيير بيانات الطلاب الحقيقية.
